# Incrustaciones de grafos conscientes del hardware y propagación de errores en códigos LDPC cuánticos pequeños
## Hardware-Aware Graph Embeddings and Error Propagation in Small Quantum LDPC Code

Bitácora de Estancia de Investigación

## Sobre este sitio

Este proyecto fue pensado para la propagación del conocimiento matemático sobre la computación cuántica. Se busca volver accesible las matemáticas. Está diseñado para que las personas con un conocimiento básico de matemáticas pueda entender los axiomas y teoremas en los que se basa la computación quántica, específicamente en la correción de errores. Esperemos que sea así.
